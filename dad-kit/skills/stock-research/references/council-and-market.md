# Market read and the family Council

## The Council

His family runs an automated research system called the Market Consciousness
Orchestra, or "the Council". Three AI analysts debate a small paper portfolio
every week, and a scorekeeper grades them against the market. It is public:

    https://github.com/GrandMastaShake/weekly-council-scan

The cast:

- **Cecil** -- the value investor. Dividends, cash flow, cheap prices on
  intact businesses.
- **Marky** -- the chart reader. Momentum, trend, volume.
- **Ophelia** -- the big-picture analyst. The Fed, interest rates, the dollar,
  oil, and which sectors are in or out of favor.

How to treat it:

- It is research input, not instructions. The picks are a paper portfolio
  being graded in public, and the scoreboard shows the grades. Mention the
  track record when he asks about a pick.
- The Butterfly Net is a watchlist, not a verdict. Its own page says so:
  check catalysts and the chart before acting.
- Check the date on whatever you read. The brief is written Saturday about
  Friday's close. By Wednesday it is history. Say how old it is.
- If the Council and a current news source disagree on a number, say both,
  with dates, and say which is newer.
- If you cannot fetch a file, say so. Do not describe what it "probably"
  says.

## Market read template

For "what's the market doing?" Search current data; date everything.

**Bottom line:** one to three sentences on the state of things and the one
thing that matters most this week.

| Item | Level | Change (period) | As of | Source |
|---|---|---|---|---|
| S&P 500 (or SPY) | | | | |
| Nasdaq 100 (or QQQ) | | | | |
| Russell 2000 (small companies) | | | | |
| 10-year Treasury yield | | | | |
| VIX (the "fear gauge") | | | | |
| Oil (WTI) | | | | |

**Breadth:** did most stocks go up, or a few big ones? Compare the regular
S&P 500 with the equal-weight version when you can. "Index up, average stock
down" is worth saying out loud.

**Rates:** when the 10-year yield rises, stocks that behave like bonds
(utilities, real estate, consumer staples) usually suffer, because a
government bond starts paying nearly as much with less risk.

**The week ahead:** dated list of the events that can move things (Fed,
CPI, PCE, jobs report, big earnings), each with what a hot or cool result
would mean.

**Plain-English version:** one short paragraph, the way the README's
"Dad Translation" boxes read.
