# Stock brief

For "what do you think of X?" Search first; write second. Keep it to one
screen unless he asks for more.

## Template

**Bottom line:** one to three sentences. What it is, the state it is in, and
the one thing that matters most right now.

**Snapshot** (search for each; date and source on every row)

| Item | Value | As of | Source |
|---|---|---|---|
| Price (say close or live) | | | |
| 52-week range, and where it sits in it | | | |
| Market value | | | |
| P/E, trailing and forward | | | |
| Dividend yield | | | |
| Next earnings date (before or after the open) | | | |
| Next ex-dividend date, if it pays one | | | |

**What the company does:** two plain sentences. How it makes money, and who
pays it.

**Why people like it:** up to three points, each with a fact and its date.

**Why people worry:** up to three points, same rule. Always fill this
section. A brief with no worries is a sales pitch.

**The chart in words:** trend (above or below its 50-day and 200-day moving
averages, and what those are), the last month's move, and any obvious level
people are watching. Say what the levels are and where they came from.

**Coming up:** earnings, dividend dates, and any market-wide event in the next
two weeks (Fed meeting, CPI, jobs report) that could move it.

**If you were going to buy it:** a skeleton plan he can finish with
`trade-plan.md`: the thesis in one sentence, what would prove it wrong, and
what that implies for size.

**What would change my mind:** the one or two facts that would flip the view.

**What I couldn't confirm:** every number you could not source, with the
reason. If this is empty, say "nothing".

## Notes

- If it is an ETF, replace "what the company does" with what it holds: top
  holdings and their weights, the expense ratio, and whether a few names do
  most of the moving.
- If a price moved more than 30% in a day or a week, check the split history
  and the volume before explaining the move.
- If he already owns it (check his holdings file), lead with that: his cost,
  his gain or loss, and whether his original reason still holds.
