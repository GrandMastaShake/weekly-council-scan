# Earnings check

## Before the report

| Item | Value | Source and date |
|---|---|---|
| Report date, and before the open or after the close | | |
| Consensus EPS (profit per share) and revenue | | |
| How it did the last four quarters vs estimates | | |
| How much the stock usually moves on earnings (or the options-implied move) | | |
| The one to three things that matter this quarter | | |

Then the honest part:

- Buying right before a report is a coin flip with a gap risk. The stock can
  open 10% away from where he bought and no stop order protects him from a
  gap. If he wants in anyway, a smaller size than usual is the normal answer.
- If he already owns it, ask what he will do on a big drop and on a big pop
  before the report, not after. A decision made in advance is a plan; one made
  at 4:05 PM is a reaction.

## After the report

**Bottom line:** beat or miss, what guidance said, and how the stock reacted
(dated: "-6% in after-hours trading on Oct 3" is not the same as a close).

| | Expected | Actual |
|---|---|---|
| EPS | | |
| Revenue | | |
| Guidance (next quarter / full year) | | |

Then the part the headline skips:

- **Costs and margins.** Did profit grow faster or slower than sales?
- **Cash flow.** Did the cash come in, or only the accounting profit?
- **The thing that mattered this quarter** from the "before" list. What did
  it show?
- **Why the stock moved the way it did.** If it beat and fell, say why the
  market did not pay for the beat. Usually it is guidance, costs, or cash.

**Plain-English version:** one short paragraph.

**What it means for his plan** if he owns it: is the original reason still
intact? Did anything hit his "what would prove me wrong" line?

## Lesson to keep in mind

Autodesk beat estimates 13 quarters in a row and the stock still fell 15.7%
the week after the 13th. General Mills beat and fell 7% that week because
costs were rising. A beat is the price of admission, not the reason a stock
goes up.
